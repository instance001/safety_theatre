# Versioning

ASEWB is revisioned by design. Keep revisions disciplined.

## Principles

- Every version change must include a written rationale.
- Deprecated indicators stay documented (with reasons).
- Changes should preserve falsifiability.

## Suggested scheme

- **Major:** changes that alter interpretation rules or indicator definitions.
- **Minor:** adding indicators, adding clarifications, or adding null cases/examples.
- **Patch:** typos, wording improvements that do not change meaning.
